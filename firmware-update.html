Important: Backup Your Configuration

Before proceeding with the firmware update, we strongly recommend creating a backup of your existing configuration.

How to Save a Backup to a USB Stick:

  1. Insert a USB stick into the OceanBridge USB port.
  2. Navigate to: Menu > System > Backup & Restore.
  3. Select 'SAVE BACKUP'.
  4. Add a name and choose USB as the location.
  5. Select 'SAVE' to store the backup.

What's New (Version 1.6.9)

New Features:

  • NMEA 2000 Device Instance Configuration: Support for configuring and persisting N2K device instance via USB stick (__n2k-instance, range 0–7) and live instance querying (info page shows the instance).
  • Enhanced Background Image Uploads: In addition to USB, background images can now be uploaded from PCs and mobile devices. For example, users can select an image directly from their smartphone's image library.
  • Live RDM Diagnostics Telemetry: Read live fixture sensor telemetry including supply voltage and PCB operating temperature, along with hardware, bootloader, and software versions (applies to RDM enabled OceanLED fixtures).
  • Light Firmware Updates via RDM: Added support to flash firmware over DMX/RDM for OceanLED RDM supported lights directly from the OceanBridge using .oled firmware files.
  • OceanLED Control Mode Configuration: Added fixture control mode selection via RDM (Switch & DMX, DMX Only).
  • Expanded Device Support: Added RDM discovery support for Sport Mini fixtures.

Improvements & Optimizations:

  • Boot Time: Optimized startup scripts.

Bug Fixes:

  • Fixed fixture blinking behavior across manual and RDM-discovered devices, ensuring blink state clears reliably.
